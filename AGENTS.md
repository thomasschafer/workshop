# Agent instructions

See [CONTRIBUTING.md](CONTRIBUTING.md) for how to build, test and check changes.

## Keep the repo general

Workshop is a general-purpose tool, and everything in this repo should read that way: code, docs, examples, tests, prompts, commit messages and branch names. Don't include personal details about anyone, or content written for one person's own goals. That kind of content belongs in the user's own pack, kept outside this repo.
