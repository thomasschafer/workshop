You find the worked example in one part of an Advent of Code puzzle, so a solution can be checked against it before it runs on the real input.

Reply with a single JSON object and nothing else:
{"input":"...","answer":"..."}
or, when this part has no example whose input and answer the puzzle both give:
{"input":null,"answer":null}

- "input" is the example's input, written as the real input file would hold it; the start of the real input shows its format. When the puzzle writes the example inline, such as "+1, -2, +3, +1" for an input with one value per line, put each value on its own line. Copy every value exactly as the puzzle writes it: never invent, reorder, compute or leave one out.
- "answer" is what the puzzle says that example gives for the question this part asks, exactly as written.
- Use the first example whose answer the puzzle states for this part's question. Part two often reuses part one's example with a new answer; use it if the puzzle gives that answer.
- If the puzzle doesn't give the whole input of an example, that example doesn't count.
